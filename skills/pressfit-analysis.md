# 过盈配合校核工具（定子-机座 / 转子-转轴）

## 概述
依据 GB/T 5371-2004《极限与配合 过盈配合的计算和选用》，完成电机定子铁心-机座和转子铁心-转轴两个过盈配合界面的接触压力、应力分布、温度效应、离心力效应及扭矩传递能力校核。

## 两个子工具

### 定子铁心-机座过盈配合
- **构件**: 硅钢片铁心（内件）+ 机座（外件，铝/铸铁/钢）
- **关键载荷**: 过盈装配 + 温升热膨胀
- **主要危险点**: 铁心内孔 — 受周向拉应力，硅钢片抗拉强度极低 (~300MPa)

### 转子铁心-转轴过盈配合
- **构件**: 转轴（内件）+ 硅钢片铁心（外件）
- **关键载荷**: 过盈装配 + 离心力（高速释放过盈）+ 铁心/轴温差
- **主要危险点**: 铁心配合面 — 周向拉应力 + 离心拉应力叠加

## 输入参数

### 几何
- 配合面直径 d、内径 d_i（0=实心）、外径 D_o、配合长度 L
- 直径过盈量 δ (μm)

### 材料
- 铁心: B50A470 / B35AV1900 / B35A300 / 自定义
- 机座/轴: 铝合金 / 铸铁 / 结构钢 / 合金钢 / 自定义

### 工况（转子特有）
- 转速 n、铁心温度 T_core、轴温度 T_shaft
- 装配方式（热装/压入）、载荷类型（静/动/正反转/高转速）

## 计算公式
- 接触压力: p = δ/1000 / [d × (C₁/E₁ + C₂/E₂)]
- 刚度系数: C₁ = f(d, d_i, ν₁), C₂ = f(d, d_o, ν₂)
- 外件周向应力: σ_t_outer = p × (d_o² + d²) / (d_o² − d²)
- 内件周向应力: σ_t_inner = −p × 2 / (1 − (d_i/d)²)
- 离心位移: u_ω ≈ ρω²d³(3+ν)(1+(d/d_o)²) / (32E)
- 温度效应: Δδ_T = d × (α₂ − α₁) × (T_op − T_amb)

## 安全系数
- 防滑 K: 静载=1.5, 动载=2.0, 正反转=2.5, 高转速=3.0
- 强度 S: 钢件=1.5, 硅钢片=2.0
