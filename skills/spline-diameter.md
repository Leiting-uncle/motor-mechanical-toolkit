# 渐开线花键参数计算工具 — Skill 定义

## 1. 功能描述

为电机工程师提供符合 **GB/T 3478.1-2008《圆柱直齿渐开线花键（米制模数 齿侧配合）》** 的渐开线花键全参数计算工具。用户在浏览器中打开单页 HTML，输入模数、齿数、公差配合等参数，即可获得分度圆、基圆、大径小径极限值、齿厚/齿槽宽公差带、跨棒距/棒间距、配合侧隙等完整工程参数。

强度校核按《机械设计手册》第五版执行 **7 项全面校核**：齿面接触、齿根弯曲、齿根抗剪、10⁸循环磨损、长期无磨损、轴扭转、轴弯曲。

核心目标：**计算准确性绝对优先**，所有公式标注标准编号，中间变量完整保留、支持人工逐行验算。

## 4. 计算公式（逐步骤）

### 4.1 基本几何（GB/T 3478.1-2008 第5章）

```
① 分度圆直径      D = m × z                                              (mm)
② 基圆直径        Db = D × cos(30°) = m × z × 0.8660254                 (mm)
③ 齿距            p = π × m                                              (mm)
④ 基本齿厚/齿槽宽  S = E = p / 2 = π × m / 2                            (mm)
⑤ 齿顶高          ha = 0.5 × m                                           (mm)
⑥ inv(30°)       = tan30° - π/6 = 0.0537515
```

### 4.2 外花键（轴）直径（GB/T 3478.1-2008 第6章）

```
⑦ 大径(基本)      D_ee = m × (z + 1)                                     (mm)
⑧ 小径(基本)      D_ie = m × (z - 1.5)  [平齿根]                         (mm)
                  D_ie = m × (z - 1.8)  [圆齿根]                         (mm)
⑨ 大径公差        IT11 (h12: 上偏差0, 下偏差-IT11)
⑩ 小径公差        IT12 (下偏差-IT12)，标注: D_ie_basic 0/-IT12
```

### 4.3 内花键（毂）直径（GB/T 3478.1-2008 第6章）

```
⑪ 大径(基本)      D_ei = m × (z + 1.5)  [平齿根]                         (mm)
                  D_ei = m × (z + 1.8)  [圆齿根]                         (mm)
⑫ 小径(基本)      D_ii = m × (z - 1)                                     (mm)
⑬ 大径公差        IT12 (H12: 下偏差0, 上偏差+IT12)
⑭ 小径公差        IT11 (H11: 下偏差0, 上偏差+IT11)
```

### 4.4 公差系统（GB/T 3478.1-2008 第8章）

```
⑮ 公差单位 i*(D)  = 0.45 × ∛D + 0.001 × D         (D≤500mm)           (μm)
⑯ 公差单位 i**(S) = 0.45 × ∛S + 0.001 × S                            (μm)
⑰ 总公差 (T+λ)    = K1 × i* + K2 × i**
     K1/K2 系数: 4级=10/40, 5级=16/64, 6级=25/100, 7级=40/160        (μm)

⑱ 齿距累积公差    Fp = A_fp × √(πD) + B_fp                             (μm)
⑲ 齿形公差        ff = A_ff × m + B_ff                                 (μm)
⑳ 齿向公差        Fβ = A_fβ × √L + B_fβ                                (μm)

㉑ 综合公差 λ = 0.6 × √(Fp² + ff² + Fβ²)                              (μm)
㉒ 加工公差 T = (T+λ) - λ                                              (μm)
```

### 4.5 齿厚与齿槽宽极限

```
㉓ 外花键作用齿厚上偏差 es_v:
    h: es_v = 0
    js: es_v = +(T+λ)/2
    k: es_v = +0.6 × D^(1/3)             (μm)
    f: es_v = -(5.5 × D^0.41)            (μm)
    e: es_v = -(11 × D^0.41)             (μm)
    d: es_v = -(16 × D^0.44)             (μm)

㉔ 外花键实际齿厚:
    S_max = S_basic + es_v/1000 - λ/1000                               (mm)
    S_min = S_basic + es_v/1000 - (T+λ)/1000                           (mm)

㉕ 内花键实际齿槽宽 (基孔制 H, EI_v=0):
    E_min = E_basic + λ/1000                                           (mm)
    E_max = E_basic + (T+λ)/1000                                       (mm)

㉖ 配合侧隙:
    最大侧隙 = E_max - S_min                                           (mm)
    最小侧隙 = E_min - S_max                                           (mm)
```

### 4.6 量棒测量（GB/T 3478.5-2008）

```
㉗ 外花键跨棒距 M_Re:
    inv(α_e) = S/D + inv(30°) + D_R/D_b - π/z
    α_e = inverseInvolute(inv(α_e))          [牛顿迭代求解]
    M_Re = Db/cos(α_e) + D_R                (偶齿数)
    M_Re = Db/cos(α_e)·cos(90°/z) + D_R     (奇齿数)

㉘ 内花键棒间距 M_Ri:
    inv(α_i) = E/D + inv(30°) - D_R/D_b
    α_i = inverseInvolute(inv(α_i))
    M_Ri = Db/cos(α_i) - D_R                (偶齿数)
    M_Ri = Db/cos(α_i)·cos(90°/z) - D_R     (奇齿数)

㉙ 推荐量棒直径: D_R ≈ 1.732m (30°压力角理论值)
    实际选取: 最接近理论值的 R40 优先数系标准量棒
```

### 4.7 强度校核（《机械设计手册》第五版 — 7 项）

#### ㉚ 转矩推算（当转矩未直接输入时）
```
T = 9550 × P / n                                   (N·m)
式中: P — 功率(kW), n — 转速(rpm)
```

#### ㉛ 齿面接触（挤压）强度 — 第3卷 花键联接
```
σ_H = 2000·T / (ψ·z·h·l·D_m)                                          (MPa)
式中: ψ=0.75(载荷不均系数), h=(D_ee-D_ii)/2(接触高度,mm),
      l=配合长度(mm), D_m≈D(平均直径,mm)
判定: n_H = [σ_H] / σ_H ≥ 1.5（通用工业），≥1.8（新能源），≥2.0（高速），≥2.5（航空）
```

#### ㉜ 齿根弯曲强度 — 第3卷 花键联接
```
σ_F = 6000·T·h / (ψ·z·S_fn²·l·D_m)                                    (MPa)
式中: S_fn≈πm/2(齿根弦齿厚,mm), h=(D_ee-D_ie)/2(全齿高,mm)
判定: n_F = [σ_F] / σ_F ≥ 1.3（通用工业），≥1.8（新能源/高速/航空）
```

#### ㉝ 齿根抗剪强度 — 第3卷 花键联接
```
τ = 2000·T / (ψ·z·S_fn·l·D_m)                                          (MPa)
式中: 切向力 F_t=2000T/D_m, 剪切面积 A=ψ·z·S_fn·l
判定: n_τ = [τ] / τ ≥ 1.3（通用工业电机）
```

#### ㉞ 10⁸ 循环磨损校核 — 第3卷 p·v 值法
```
v_s = π·h·n / 60000                                                     (m/s)
p·v = σ_H × v_s                                                         (MPa·m/s)
式中: v_s — 齿面平均滑动速度, h — 接触高度(mm), n — 转速(rpm)
10⁸循环总滑动距离: L_s = v_s × (10⁸/n/60) × 3600                       (m)
判定: n_pv = [p·v] / (p·v) ≥ 1.5
```

#### ㉟ 长期工作无磨损校核 — 第3卷 微动磨损门槛
```
σ_H ≤ [σ_Hw]                                                             (MPa)
式中: [σ_Hw] — 材料无磨损许用接触应力，取决于材料与硬度
      σ_H 低于此门槛值时，即使长期交变载荷也不发生显著微动磨损
适用工况: 长寿命(>10⁹循环)、维护困难、要求零磨损的场合
```

#### ㊱ 外花键轴扭转强度 — 第2卷 轴的设计
```
τ_max = T / W_t = 16000·T / (π·D_ie_min³)                               (MPa)
式中: W_t = π·d³/16（实心轴抗扭截面模量）, d = D_ie_min（外花键小径最小值）
判定: n_τ = [τ] / τ_max ≥ 1.3
```

#### ㊲ 外花键轴弯曲强度（弯扭合成） — 第2卷 轴的设计
```
σ_b = M / W_b = 32000·M / (π·D_ie_min³)                                 (MPa)
σ_e = √(σ_b² + 3·τ_max²)              [第四强度理论，弯扭合成应力]        (MPa)
式中: W_b = π·d³/32（实心轴抗弯截面模量）, M — 轴上弯矩(N·m)
判定: n_e = [σ] / σ_e ≥ 1.3
注: 未提供弯矩值时跳过此项校核，仅输出截面模量供参考
```

## 5. 安全系数判定标准

### 5.1 齿面接触与齿根弯曲（按行业分级，内部判定）

| 行业场景 | 接触强度 n_H | 弯曲强度 n_F | 抗剪强度 n_τ | 依据 |
|----------|:---:|:---:|:---:|------|
| 通用工业电机 | ≥1.5 | ≥1.3 | ≥1.3 | 《机械设计手册》第五版 |
| 新能源汽车驱动电机 | ≥1.8 | ≥1.8 | ≥1.8 | GB/T 18488-2024 |
| 高速永磁电机 (≥10000rpm) | ≥2.0 | ≥2.0 | ≥2.0 | 高速电机设计规范 |
| 航空级电机 (eVTOL) | ≥2.5 | ≥2.5 | ≥2.5 | 航空级失效概率要求 |

> **注意**：当前界面简化为统一使用「通用工业电机」标准（n_H≥1.5, n_F≥1.3），行业场景判定在 calc.js 内部的 `SAFETY_STANDARDS` 中保留，可通过 `industry` 参数切换。

### 5.2 磨损与轴校核（统一标准）

| 校核类型 | 安全系数 | 说明 |
|----------|:---:|------|
| 10⁸循环磨损 p·v | ≥1.5 | p·v 值法，确保 10⁸次循环磨损量在许用范围内 |
| 长期无磨损 | 裕度 m≥1.0 | σ_H ≤ [σ_Hw] 即满足，m = [σ_Hw]/σ_H |
| 轴扭转 | ≥1.3 | 同通用工业弯曲标准 |
| 轴弯曲（弯扭合成）| ≥1.3 | 第四强度理论，仅在有弯矩输入时校核 |

## 7. UI 要求

### 7.1 布局
- **左侧固定面板**（380px）：参数输入区，sticky 定位。分为基本参数区 + 强度校核参数区（折叠可选）

|------|------|

| 🔧 外花键（轴） | 大径/小径（机械制图公差标注 `φ52 0/-0.173`）、渐开线起始圆、齿厚范围、跨棒距 |
| 🔩 内花键（毂） | 大径/小径（公差标注 `φ53 +0.279/0`）、渐开线终止圆、齿槽宽范围、棒间距 |
| 📏 公差明细 | (T+λ)、λ、T、Fp、ff、Fβ 及计算式 |

- **CSS 变量体系**：统一在 `:root` 中定义

### 7.5 交互
- 所有结果卡片可**点击标题折叠/展开**
- 底部提供**"中间计算详情"**展开区，展示逐步骤公式代入过程
- 预设**快速示例按钮**（电机轴花键 / 小模数 / 大模数），含完整强度参数
- 量棒直径根据模数**自动推荐**，也可手动输入
- 配合长度留空时自动取 1×D
- 转矩可通过直接输入或功率+转速自动推算（T=9550·P/n）

### 7.6 打印
- `@media print` 隐藏输入面板
- 仅保留计算结果卡片

## 9. 红线禁令

1. **禁止** 在 `index.html` 中编写任何计算公式
2. **禁止** 在 `calc.js` 中操作 DOM 或引用界面元素
3. **禁止** 在 `data.js` 中包含任何计算逻辑
4. **禁止** 合并计算步骤、省略中间变量
5. **禁止** 修改国标公式的系数、修正项而不标注来源
6. **禁止** 统一使用单一安全系数阈值 — 接触/弯曲/剪切/磨损/轴校核各有独立判定标准
7. **禁止** 忽略转速、材料等电机工况参数的影响 — 磨损校核依赖转速计算滑动速度
8. **禁止** 直径显示拆分为 basic/max/min 三行 — 统一使用机械制图公差标注

## 10. 验证用例

### 用例 1: 电机轴花键（标准工况 + 全7项校核）
```
输入: m=2, z=25, 6级, H/h, 平齿根, L=50mm, T=500N·m,
      P=75kW, n=1500rpm, 40Cr调质, M=0
期望输出:
  基本: D=50mm, Db=43.301mm
  外花键: D_ee=φ52 (52 0/-0.173), D_ie=φ47 (47 0/-0.267)
  内花键: D_ei=φ53 (53 +0.279/0), D_ii=φ48 (48 +0.168/0)
  公差: (T+λ)≈109μm, S_max≈3.080mm, S_min≈3.033mm, 最小侧隙≈0.124mm
  强度:
    ① 接触 σ_H≈10.7MPa, n_H≈13.1, 合格 (≥1.5)
    ② 弯曲 σ_F≈16.2MPa, n_F≈10.5, 合格 (≥1.3)
    ③ 抗剪 τ≈6.8MPa, n_τ≈12.5, 合格 (≥1.3)
    ④ 磨损 p·v≈1.68MPa·m/s, n_pv≈2.09, 合格 (≥1.5)
    ⑤ 无磨损 σ_H=10.7 ≤ 60, 裕度5.6, 无磨损 ✓
    ⑥ 扭转 τ_max≈25.0MPa, n≈3.4, 合格
    ⑦ 弯曲 —（未提供弯矩，跳过）
```
