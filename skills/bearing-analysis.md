# 滚动轴承校核计算工具

## 概述
参照 SKF 滚动轴承综合型录和 NSK 超精密轴承目录，结合 ISO 281:2007 标准，计算电机轴承的寿命、静强度、润滑、摩擦功耗、配合游隙及轴系力学特性。

## 两种计算模式

### SKF 模式（常规转速 n < 5000rpm）
- ISO 281:2007 基本额定寿命 L₁₀
- SKF 修正寿命 L_nm = a₁ × a_SKF × L₁₀
- 当量载荷 P = X·F_r + Y·F_a（X/Y 系数按 GB/T 6391 迭代）
- 静强度 s₀ = C₀/P₀（GB/T 4662）
- 粘度比 κ = ν/ν₁（SKF 图1 双线性插值）
- 摩擦功耗（滚动 Mrr + 滑动 Msl 模型）
- 配合推荐（轴/座孔公差等级）
- 游隙推荐（C2/CN/C3/C4/C5）
- 再润滑周期

### NSK 模式（高速 n > 5000rpm）
- 预紧力 → 轴向/径向刚度计算
- dm·n 速度参数 + 极限转速修正（保持架×球材料×精度×预紧系数）
- DB/DF/DT 排列方式、隔圈长度差
- 陶瓷球轴承寿命修正

## 内置轴承目录（30+型号）
6203-6215, 6306-6314, NU306-NU314, 7306B-7312B, 30206-30212

## 轴系力学分析（可选）
- Rayleigh 法弯曲临界转速（考虑轴承弹性支承）
- 弹性支承梁最大挠度
- 扭转固有频率（基于极惯性矩）

## 输入参数
- 轴承类型、型号来源（数据库选型/手动输入）
- 径向/轴向载荷 F_r, F_a、转速 n
- 润滑方式（油/脂）+ 工作温度 + 清洁度
- 可靠度（90%~99%）、工况类型

## 标准依据
- ISO 281:2007 滚动轴承 额定动载荷和额定寿命
- GB/T 6391-2010 滚动轴承 额定动载荷和额定寿命
- GB/T 4662-2012 滚动轴承 额定静载荷
- ISO 3448 工业液体润滑剂 ISO 粘度分级
- SKF General Catalogue
- NSK Super Precision Bearings Catalogue
